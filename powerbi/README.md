# Power BI Report

The complete report file is:

```text
powerbi/FashionDW.pbix
```

If this repository was downloaded through the split Windows package, download
`FashionDW.pbix` separately and copy it into this folder before opening the
project.

The PBIX file is tracked with Git LFS because it is a large binary artifact.
Install Git LFS before pushing or cloning the complete repository:

```bash
git lfs install
```

The `images/` directory contains report-page previews that render directly on
GitHub. Correct reusable measures are documented in `measures.dax`.
